📝 To-Do List App

A simple and interactive To-Do List built with HTML, CSS, and JavaScript.
It helps you organize your daily tasks with ease, featuring add, edit, delete, and clear-all functionality.

🚀 Features

➕ Add new tasks

✏️ Edit tasks by double-clicking

🗑️ Delete individual tasks

❌ Clear all tasks at once

💻 Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)
